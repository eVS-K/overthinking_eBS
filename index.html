ゲームルール

7枚のカードを一度ずつ使い、相手の一手を読み合う二人用カードゲームです。

  1. 準備二人とも A / K / Q / J / Joker / 3 / 2 の7枚を持って始めます。
  2. 勝負毎ラウンド、互いに残り手札から1枚を選んで同時に公開します。
  3. 獲得勝った人は、そのラウンドの2枚と持ち越し札をすべて獲得します。
  4. 終了獲得が9枚以上になった時点、または7ラウンド後に獲得枚数が多い人の勝ちです。

まずは通常の強さ

A が最も強く、通常は A ＞ K ＞ Q ＞ J ＞ 3 ＞ 2 です。Joker は相手と同じ強さになり、通常は引き分けます。

2 は A に勝つ3 は Joker に勝つ

カードの組み合わせ早見表

行があなた、列が相手です。勝＝あなたの勝ち、負＝あなたの負け、分＝引き分け。

自分＼相手AKQJJoker32

K負分勝勝分勝勝

Joker分分分分分負分
3負負負負勝分勝
2勝負負負分負分

引き分けの場合出した2枚は誰にも入らず「持ち越し札」になります。次に勝った人が、持ち越し札もまとめて獲得します。

ポイントこれは単なる運任せのゲームではありません。残り札・スタック・相手の選択から局面を読み、より有効な一手を選ぶことが勝利への鍵です。
